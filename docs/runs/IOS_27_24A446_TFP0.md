# iPhone 11 `24A446`: tfp0 kernel read/write

- Device: iPhone 11 (`iPhone12,1`, `n104ap`)
- OS: iOS 27.0.1 (`24A446`)
- Kernel: XNU `13432.2.10~2/RELEASE_ARM64_T8030`, arm64e
- Result: PID 0 task port, live kernel base, and scratch-allocation kernel
  read/write confirmed

`fw get-boot --tfp0` adds the four patches used by `libkrw0-tfp0`. The
implementation follows the [PongoOS KPF reference](https://github.com/burnegg/PongoOS/tree/0bcdeed02df72f91c1e405cfe4c4994e0084f839)
and finds each site with a unique relocation-tolerant instruction sequence.

| Patch | Offset | Original | Replacement |
| --- | ---: | --- | --- |
| task conversion | `0x31b6640` | `1f0009eb` | `ff031feb` |
| PID zero | `0x36bf37c` | `f7070034` | `1f2003d5` |
| kernel map | `0x31b7fa8` | `41010054` | `0a000014` |
| live slide through `TASK_DYLD_INFO` | `0x32003f8` | `88f241f9c80200f988f641f9` | `68d3feb008b547f9df0200f9` |

## Runtime result

The probe ran as root with `task_for_pid-allow` and `libkrw0-tfp0` installed.
It validated the top-level kernelcache UUID before it allocated memory.

```text
kbase error=0 address=0xfffffff0413c4000
kread-header error=0 magic=0xfeedfacf ncmds=256 sizeofcmds=18272
kread-load-commands error=0
kernel_uuid=0DA8A87A-1F69-7827-274B-DAB635F0DDCF
kernel_slide=0x3a3c0000
RESULT libkrw-kbase-ok
kmalloc error=0 address=0xffffffea70e14000
kwrite error=0
kread error=0 data=6c69626b72772d72:6561642d77726974
kdealloc error=0
RESULT libkrw-scratch-rw-ok
```

The live base equals the unslid base `0xfffffff007004000` plus the reported
slide `0x3a3c0000`. This proves that the slide transport and read/write access
to writable kernel allocations work through the PID 0 task port. It does not
prove writes to SPTM-protected memory or the separate SPTM bug hypothesis.

The first `bootx` attempt returned to pwned DFU before userspace. An identical
retry booted normally and passed the full probe. This run does not establish a
cause for the first boot failure. Runtime was tested on 24A446. Exact fixtures
also cover 24A435. Other builds are disabled.
